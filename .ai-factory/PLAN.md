# Implementation Plan: mimikkai-connect CLI (packages/cli)

Branch: none (fast mode)
Created: 2026-09-17

## Original Request
Взять наработки из @z_ai/coding-helper (структура CLI, паттерны настройки агентов, i18n, doctor) и сделать в packages/cli пакет `mimikkai-connect` на Bun + TypeScript. Команды: `-h/--help`, `-v/--version`, `init` (мастер), `lang show|set`, `auth` (интерактивно / `auth glm_coding_plan_global <token>` / `auth glm_coding_plan_china <token>` / `auth revoke` / `auth reload claude`), `doctor`. Авторизация mimikkai.ru — по образцу mimikkai-connector-copilot/src/auth (device flow + GraphQL validation). Решения пользователя: агент конфигурирует LiteLLM (`https://litellm.mimikkai.ru`), в v1 реализовать claude-code + codex, дефолтная модель `glm-5.3-flash`, конфиг в `~/.mimikkai-connect/config.yaml`, режим fast.

## Settings
- Testing: no (ручная проверка CLI в задачах верификации)
- Logging: verbose (DEBUG-логи через утилиту логгера, уровень через env `MIMIKKAI_LOG_LEVEL`)
- Docs: no (WARN [docs] только)

## Research Context (informal)
Источники (read-only, вне репозитория):
- Распакованный пакет `@z_ai/coding-helper@0.1.1` (npm): `dist/lib/config.js` (`~/.chelper/config.yaml`, js-yaml, singleton ConfigManager), `dist/lib/claude-code-manager.js` (запись `~/.claude/settings.json`: `env.ANTHROPIC_AUTH_TOKEN`, `env.ANTHROPIC_BASE_URL`, `API_TIMEOUT_MS`, чистка shell rc; `~/.claude.json`: `hasCompletedOnboarding`, `mcpServers`), `dist/lib/codex-manager.js` (`~/.codex/config.toml`: `model_providers.<KEY> = {name, base_url, experimental_bearer_token, wire_api}`, `model`, `model_reasoning_effort`; `~/.codex/models.json`: запись модели), `dist/lib/wizard.js` (inquirer + ora + chalk), `dist/locales/{en_US,zh_CN}.json` (i18n-словари), `dist/commands/doctor.js`.
- `C:\Users\dealenx\Projects\work\mimikkai\mimikkai-connector-copilot\src\auth\`: `mimikkaiDeviceAuthClient.ts` (POST `{service}/api/auth/device/authorize` → `{device_code, user_code, verification_uri, verification_uri_complete, expires_in, interval}`; rewrite host `service.mimikkai.ru` → `panel.mimikkai.ru`; POST `{service}/api/auth/device/token` polling: 202 `authorization_pending` → sleep(interval), 200 → `{token, user}`, 400 `expired_token`; сетевые ретраи backoff 1s×2^n, макс 3), `mimikkaiTokenClient.ts` (GraphQL `userViewer` query, POST `{service}/graphql`, Bearer token → `{valid, user}`), `mimikkaiAuthTypes.ts` (`MimikkaiAuthConfig`: authServiceUrl, frontendUrl, litellmBaseUrl, clientName), `mimikkaiAuthErrors.ts`, `mimikkaiLitellmKeyClient.ts` (получение LiteLLM virtual key).
- Важное отличие от z.ai: у mimikkai одна точка `litellm.mimikkai.ru` — планы `glm_coding_plan_global|china` в синтаксисе `auth` НЕ меняют URL (зарезервированы как алиасы, обе ветки пишут один и тот же baseUrl). Значение ключа в конфиг агента — LiteLLM virtual key (`sk-...`), полученный после логина; введённый `<token>` в `auth <plan> <token>` — это API-ключ mimikkai, валидируемый через GraphQL.
